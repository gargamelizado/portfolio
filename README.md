## Projetos em destaque

### 1. Chock Trufas em React
- Descrição: sistema de catálogo e pedidos para uma confeitaria, com fluxo pensado para facilitar o atendimento e a conversão via WhatsApp.
- Stack: React, Node.js, Express, API REST, JWT
- Repositório: [Chock Trufas](https://github.com/gargamelizado/Chock-Trufas/tree/main/chock-trufas-react)

### 2. Burger Heaven
- Descrição: landing page comercial para hamburgueria com foco em identidade visual, apresentação do cardápio e conversão.
- Stack: HTML5, CSS3, responsividade
- Demonstração: disponível na aplicação

### 3. Clínica Médica
- Descrição: website institucional para clínica, com foco em organização visual, credibilidade e apresentação de serviços.
- Stack: HTML5, CSS3
- Demonstração: disponível na aplicação

## Requisitos

Antes de executar o projeto, certifique-se de que o ambiente possui:

- Node.js 18+
- npm

## Instalação

```bash
npm install
```

## Scripts disponíveis

```bash
npm run dev
```

Inicia o servidor de desenvolvimento local.

```bash
npm run build
```

Gera a build de produção da aplicação.

```bash
npm run preview
```

Prepara e disponibiliza a build para visualização local.

```bash
npm run test
```

Executa a suíte de testes do projeto.

```bash
npm run lint
```

Valida o código com ESLint.

## Como executar localmente

1. Instale as dependências:

```bash
npm install
```

2. Inicie a aplicação:

```bash
npm run dev
```

3. Acesse a URL exibida no terminal, normalmente:

```text
http://localhost:5173
```

## Observações

- A preparação das demonstrações dos projetos é executada automaticamente antes do desenvolvimento e da build.
- A aplicação inclui navegação por rotas e páginas de demonstração para cada item do portfólio.
- O projeto está preparado para deploy em ambientes como Vercel.
