## 🔍 Guia de Busca Rápida

### Encontrar um Componente
1. Procure em **PROJECT_MAP.md** > Estrutura de Componentes
2. Copie o path exato
3. Abra em seu editor

### Encontrar um Arquivo
1. Use **PROJECT_MAP.md** > Árvore Completa
2. Ou procure em **MAPA_RAPIDO.md** > Estrutura Pastas

### Entender um Componente
1. **PROJECT_MAP.md** - localizar e visualizar
2. **ESTRUTURA_DOC.md** - descrição completa
3. **CÓDIGO.jsx** - ler implementação

### Mudar um Estilo
1. **PROJECT_MAP.md** > Sistema de Estilos
2. **MAPA_RAPIDO.md** > Assets/Cores
3. Arquivo CSS - fazer mudança

### Adicionar Feature
1. **GUIA_RAPIDO.md** - ver roadmap
2. **ESTRUTURA_DOC.md** - entender padrões
3. **PROJECT_MAP.md** - localizar onde adicionar
